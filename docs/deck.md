# Deck

A seven-slide introduction to the suite for the team or leadership: the problem at sixty sessions, the four planes, how a ticket becomes a merged PR, how the harness improves on evidence, governance, and where things stand.

[Open the slides](deck/){ .md-button .md-button--primary } [Download the PDF](deck/agent-factory.pdf){ .md-button }

Use the arrow keys, the buttons in the corner, or swipe. Printing from the browser gives one slide per page. The source is [`deck/src.html`](https://github.com/Sean-Koval/agent-factory/blob/main/deck/src.html); `python3 scripts/build_deck.py --pdf` rebuilds the page and the PDF with the current Airframe theme.
