The tools meet only at versioned files and APIs. Each row links to the repo that defines the contract; this page indexes them and never copies their schemas. Tower and Spaceport are private repositories, so their files and issues are named without links. [How it fits](../how-it-fits.md) shows the same seams along a ticket's journey.

| Producer → consumer | Contract | Defined in | Status |
| --- | --- | --- | --- |
| ai-dlc → team harness repo → hangar | Workflow plugin with `plugin.lock.json`, pinned in a harness lock as the component `plugin:ai-dlc-workflow@team-harness` (plugin name and marketplace), with its digest in the component's own `digest` field | [ai-dlc#191](https://github.com/Sean-Koval/ai-dlc/issues/191), [#193](https://github.com/Sean-Koval/ai-dlc/issues/193), [hangar#221](https://github.com/Sean-Koval/hangar/issues/221) | Plugin and lock support on main; the team's harness turning it on: [hangar#139](https://github.com/Sean-Koval/hangar/issues/139) |
